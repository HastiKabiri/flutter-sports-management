JM Hockey Academy is a Flutter prototype for managing a hockey academy. Its source contains a public academy page and role-specific workspaces for administrators, coaches, players, parents, and performance analysts.

## Project imagery

<img src="assets/IMG_8519.jpg" alt="Hockey academy photograph bundled with the app" width="600" />

This photograph is a project asset. An application screenshot is pending a runnable build.

## Prototype modules

- Public onboarding, academy information, news, and gallery.
- Role-specific dashboards and profile views.
- In-memory chat and time-limited attendance codes.
- Theme, text size, notification, and language settings.
- Firebase Auth and Firestore integration code alongside prototype workflows.

## Getting started

Use a Flutter SDK with Dart 3.11.5 or newer in the Dart 3 series. From the repository root:

```sh
flutter pub get
flutter analyze
flutter test
```

The current entry point has compile and initialization issues. A successful launch and hosted Firebase workflows remain unverified.
